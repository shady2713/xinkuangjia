# 菜单组件

## 摘要

提供 Vue 菜单、普通菜单项和徽标组件，用于前端导航菜单展示。

## 目录

- [使用](#使用)
- [已知限制与暂缓工作](#已知限制与暂缓工作)

## 使用

在当前前端工作区接入 `@vben-core/menu-ui`，从 [公开入口](src/index.ts) 选择组件与类型。`Menu` 接收调用方提供的 `menus` 数据，菜单模式、折叠和激活项等属性见 [类型定义](src/types.ts)。组件由消费应用在 Vue 环境中使用。

## 已知限制与暂缓工作

仅提供 Vue 菜单组件及类型，不能作为独立应用运行；需配合工作区依赖。菜单数据由调用方提供，属性约定见 [类型定义](src/types.ts) 和 [菜单入口](src/menu.vue)。
