# 模板：package-bundle

本模板用于组合多个组件的分发包或预设。根据目标项目的包清单、构建或发布配置确认组成和接入方式，不假定特定框架字段或目录。

组合包 README 以实际安装、启用方式及组成关系开头；实现部分解释组合机制和配置优先级。兼具独立调用接口时，据实说明其入口和边界。

<a id="frontmatter"></a>

## 前置元数据

```yaml
---
description: "说明该组合包提供哪些能力，适用于什么使用或配置场景。"
kind: "package-bundle"
---
```

<a id="skeleton"></a>

## 骨架

页面结构遵循[页面顺序](../references/structure-hierarchy.md#page-order)：标题默认中文，项目机器规则要求的标题保留；分隔线和开发笔记均可省略，不强制分隔线样式、空行和锚点前后位置，也不强制开发笔记数量、标题层级或末尾位置。已有开发者实现细节与开发笔记正文仍须折叠，必要操作、限制和警告保持可见。

按目标项目的实际命令、配置和公开入口填写示例，不保留占位说明。仅在涉及模型交互时保留“模型体验”章节及其目录项；该部分按[包 README 评审标准](../references/review.md#package-readme-review)编写。

## 使用此包

确认安装条件和启用方式，并核对组合包实际提供的能力。

### 安装与启用

填写目标项目实际支持的安装、启用和移除步骤，并说明前置条件、可观察结果及失败恢复方式。若组件随产品提供，说明启用入口；未提供独立安装或移除操作时如实说明，不虚构命令。

<a id="what-you-get"></a>

### 你会得到什么

<a id="rules"></a>

## 规则

- **核实组合关系。** 读取目标项目实际的包清单、构建或发布配置，确认包含的组件、启用条件和配置优先级。
- **验证使用路径。** 在适用的测试环境中按项目实际方式安装或启用组合包，核实组成、冲突及失败处理；按主技能的事实核查流程验证受支持的移除步骤。
