# 模板：persistence-release

本模板用于比较两个明确发布版本的持久化结构，记录观察到的差异。它不代替变更确认、迁移验收或兼容性结论；需要这些决策时链接相应的变更记录。记录目录、命名和发布标识遵循目标项目，不要求特定标签前缀。

<a id="frontmatter"></a>

## 前置元数据

必须满足[元数据核验规则](../references/metadata-links.md#metadata-verification)，`kind` 固定为 `persistence-release`。

```yaml
---
description: "比较指定发布版本的持久化结构，说明差异、来源和提取范围，供追溯版本变化时查阅。"
kind: persistence-release
---
```

<a id="sections"></a>

## 章节

页面结构遵循[页面顺序](../references/structure-hierarchy.md#page-order)：标题默认中文，项目机器规则要求的标题保留；分隔线和开发笔记均可省略，不强制分隔线样式、空行和锚点前后位置，也不强制开发笔记数量、标题层级或末尾位置。已有开发者实现细节与开发笔记正文仍须折叠，必要操作、限制和警告保持可见。

1. **摘要：** 指明比较的前后发布版本、主要差异或无差异结论及其覆盖范围。项目有独立格式版本时，同时报告实际值，不能从发布名称推断。
2. **目录：** 链接后续章节，保持锚点稳定。
3. **发布证据：** 分别记录能准确定位的发布标识、对应源码或产物、结构定义及提取方式，链接前一条相关记录。首次记录须说明基线；比较区间有跳跃时明确遗漏版本，不称为相邻版本比较。
4. **比较声明：** 明确两个版本、比较对象、纳入与排除范围，以及对应结构证据。项目有机器声明或附件规范时严格遵循；没有时用明确字段或表格记录，不强制某种 YAML 块、JSON 附件或摘要算法。
5. **结构变更：** 列出对象或字段、变更前后约定及差异来源。人工比对和机器检测分别标明；没有差异也是有范围的结果，不能用空记录代替核验。
6. **验证与限制：** 记录实际提取、重建或比对方法、工具版本、命令和结果，以及无法还原的部分。结构比较不证明历史读写行为、迁移安全或兼容性。
7. **开发笔记（可选）：** 只保留非权威工作上下文，无内容时省略；位置和标题层级按正文组织。

<a id="snapshot-and-history-rules"></a>

## 快照与历史规则

- 发布来源必须可定位。提取失败或历史产物缺失时明确记录缺口，不用当前结构冒充历史版本，也不将尚未发布的源码状态描述为正式发布。
- 有项目生成器或验证器时使用实际命令，保留其要求的结构定义、附件、清单及摘要；生成区域与人工解释分开维护，不手改机器产物或通过删除文件绕过验证。
- 没有专用工具时，可以人工比对可追溯的结构证据，但必须记录方法和覆盖范围，不声称完成了未执行的重建或自动检查。
- 为每侧保留足以复核比较范围的结构证据及必要依赖定义。记录原有字段类型、可选性、约束和不透明内容；未知信息明确标注，不补写为猜测的事实。
- 历史观察与当前变更确认分开维护。按项目历史记录政策处理更正和后续版本，不为适应旧发布而修改当前基线，也不为匹配当前规则重写历史证据。
