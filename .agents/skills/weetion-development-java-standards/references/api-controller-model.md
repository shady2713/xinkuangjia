# 接口契约与模型转换

用于新增或修改 HTTP、跨模块 API、请求响应模型及转换逻辑。

## 入口与认证

HTTP 入口按用途放入 `controller/admin`、`app`、`open` 或 `compat`。管理业务沿用项目权限标识和 `@PreAuthorize`，同时核对对象归属与数据范围；菜单权限不代替对象授权。

登录和公开资源使用明确的最小放行范围；按各自协议选择身份机制及必要的签名、防重放或限流。认证配置缺失时失败关闭。安全链及 `permit-all` 的实际行为见[安全框架](project-framework.md#安全链与数据边界)。

复杂请求与分页使用明确 VO，简单标量查询参数可直接声明。普通响应复用 `CommonResult` 和 `PageResult`；流式、文件及第三方协议响应按其契约处理。

## 模型边界

- 跨模块能力由提供方 API 暴露，使用稳定 DTO，不暴露内部 Service、Mapper、DO 或第三方 SDK 实现类型。
- HTTP 请求与响应不直接使用 DO。简单同模块只读查询可接收 Service 返回的 DO，在入口立即转换，不修改后回写或跨模块传递。
- 稳定字段用明确类型；结构确实动态的第三方数据在适配边界解析和校验，不将原始 Map 扩散成公共业务模型。
- 审计时间等字段是否返回由接口用途决定。

## 凭证输出

认证接口可向合法调用方签发凭证，专用客户端可通过 DTO 向目标服务传递凭证；接收者范围与日志裁剪随用途验证。普通管理页面仅展示服务端秘密的配置状态或必要掩码。

## 更新与兼容

局部更新需要区分“未提供、清空、设值”时，模型、反序列化与写入策略共同保留三态。完整替换或不支持清空的协议按既定契约处理；Bean 拷贝不得改变缺省字段的语义。

数据库、缓存和对象存储的配置修改见[集成边界](project-framework.md#配置与运行)；只有临时兼容旧字段、旧状态或旧路径时才记录退出条件。

## 模型转换

同构字段可复用项目 BeanUtils 或既有 MapStruct Convert；脱敏、权限裁剪、单位换算和兼容默认值使用可核对的显式转换规则。转换不能暗中查询数据库或改变业务状态。

字段说明按[注释标准](java-comments.md)，验证范围见[测试指南](testing-validation.md)。
