# 需求卡目录约定

## 摘要

需求卡按当前项目的模板、来源和编号约定维护；日常源码与文档发现不自动读取此目录的计划或卡片。

## 目录

- [检索范围](#检索范围)
- [生成入口](#生成入口)
- [已知限制与暂缓工作](#已知限制与暂缓工作)

<a id="检索范围"></a>

## 检索范围

常规 rg 枚举、正文检索和自动读取链接时排除 `docs/需求卡/**`。仅在用户明确请求、提供具体路径或当前任务执行/检查该计划或卡时读取相关内容；该要求不免除质量检查。

<a id="生成入口"></a>

## 生成入口

生成前读取[需求卡技能](../../.agents/skills/weetion-task-cards/SKILL.md)及对应模板；先维护已确认来源，不从产物反推需求。当前目录只维护入口，不预建需求或任务。

## 已知限制与暂缓工作

当前没有已确认的需求卡，目录入口不代表任何计划已获执行授权。创建卡片时须按对应技能读取模板并核实来源。
