# 前端测试与交付工具

## 摘要

管理前端提供测试代理隔离、V8 覆盖率、构建体积分析以及静态站点打包、核验和环回 HTTP 冒烟。所有入口在当前前端根执行，不发布或部署服务；覆盖率报告存在不代表测试通过，静态资源可读也不能证明浏览器、登录或后端接口已验收。

## 环境与入口

在 [管理前端根](../../前端代码/basic-framework-admin/)执行命令，需要 Python 3.10+、Node.js、pnpm 和锁文件依赖，详见[质量检查环境](质量检查脚本.md#准备环境)。端到端执行还需要对应 Playwright 浏览器和生产 dist；测试范围见[测试策略](../测试与可靠性/测试策略.md)。

工具位于前端 scripts/quality，代理字段、允许资源类型和上限由 [delivery_rules.py](../../前端代码/basic-framework-admin/scripts/tools/delivery_rules.py)维护。构建记录使用 [build_record.py](../../前端代码/basic-framework-admin/scripts/quality/build_record.py)，分析功能由当前 Vite 配置包提供。

## 测试代理隔离

包装器只修改新测试子进程的环境，不改变终端、系统或其他进程。默认 local 在 Node 启动前清除 HTTP、HTTPS、ALL、FTP、npm 代理及 NODE_USE_ENV_PROXY，合并 NO_PROXY 并补充 localhost、127.0.0.1 和 ::1，不打印代理值。

```powershell
pnpm test:unit:isolated
pnpm test:unit:isolated --proxy inherit
# 只列出 E2E 用例，不执行浏览器验收
pnpm test:e2e:isolated -- --list
```

inherit 用于确需机器代理的专项外部链路。包装器不阻止网络，也不覆盖测试自身设置的代理。`--timeout` 接受正整数秒，默认整组 600 秒；超时退出 124，中断 130，启动或清理错误 2，普通测试失败保留原退出码。超时与取消会清理本次创建的进程树。

`--` 后的参数原样传给 Vitest/Playwright。unit 使用 run 模式；当前 e2e 选择应用 [playwright.config.ts](../../前端代码/basic-framework-admin/apps/web-ele/playwright.config.ts)，在前端根显式配置调用。列表不要求已启动浏览器，实际执行要求浏览器与预览服务条件。

## 覆盖率与未覆盖位置

先运行当前版本测试生成覆盖率，再读取未覆盖位置。工具不会替旧报告补跑测试。

```powershell
pnpm test:coverage
pnpm test:coverage --coverage-stage full
pnpm coverage:uncovered
pnpm coverage:uncovered --json
```

`test:coverage` 使用 Vitest 与 V8 提供器，枚举 apps、packages 和 internal 下的生产 src，包括未被加载的实现。配置位于 [vitest.config.ts](../../前端代码/basic-framework-admin/vitest.config.ts)。默认 audit 明确报告覆盖缺口；`--coverage-stage full` 或 `release` 对每个手写生产文件要求行与函数全部覆盖，不用全库平均值或可下调百分比抵消缺口。

包装器清理本次旧报告、绑定输入，并保留测试失败退出码；缺失文件、空报告、无依据的零计数及测试期间输入变化都不能通过。TypeScript 纯声明由真实语法树核实为不适用，并保留 V8 原始占位计数，不伪造覆盖率。共享包及来自上游的手写实现仍纳管；测试、生成物与声明按各自职责分类。

前端 `coverage/coverage-final.json` 保存 Istanbul 数据，`coverage/index.html` 用于阅读。位置工具报告零计数语句、函数与分支的相对路径、行列，数量不等于未覆盖行数。列号从 1 开始；Vue 映射的未知列在 JSON 中为 null，不伪造精确位置。缺报告或格式无效退出 2，有未覆盖位置仍退出 0。源码变化后必须重新生成，报告存在不能证明当前测试成功或权限链路完备。

## 构建体积分析

分析模式使用独立缓存目录，不覆盖生产 dist；分析产物不能直接认领为同配置的生产构建。

```powershell
pnpm build:analyze
```

输出前端 `.cache/analyze` 下的构建体积报告.md、构建体积报告.json 及该次分析构建。Markdown 按 JavaScript 分块实际 UTF-8 字节数排序，并给 gzip 字节；JSON 中 Rollup renderedLength 只用于定位组成，不代表压缩后精确占比、Brotli 体积或浏览器加载时间。报告不统计 public 复制文件，不生成 sourcemap。

分析与 production 使用各自模式配置；大分块提示不等于运行性能差。比较体积时记录准确版本、模式、入口及原始报告，运行性能按[性能调查](../性能优化/性能调查与证据.md)独立测量。

## 静态站点交付

按顺序关联来源与生产产物，再打包、核验和冒烟；每一步成功才进入下一步。修改源码或锁文件后重建，不为旧产物手工补记来源。

```powershell
pnpm build:recorded
pnpm release:pack
pnpm release:verify
pnpm release:smoke
```

pack 先通过构建记录验证，只把 `apps/web-ele/dist` 写入 `.cache/release/前端交付包.zip`，附交付清单.json。清单记录应用版本、来源、站点前缀、逐文件大小和 SHA-256；版本取 [应用 package.json](../../前端代码/basic-framework-admin/apps/web-ele/package.json)，不取根工作区版本。来源或产物在打包期间变化则失败。

verify 仅读 ZIP，核对路径、类型、上限、文件集合与摘要。需要限定目标版本时使用 `pnpm release:verify --expected-version 5.6.0`，数字应换为实际交付应用版本；smoke 支持相同参数。摘要不是签名，不证明来源可信或制品未被整体伪造。

smoke 验证后解压到私有临时目录，在随机环回端口提供静态 HTTP，读取首页与 HTML 入口 script/link，核对内容一致且不继承代理。漏文件或外部入口资源失败，不从源码补齐；结束回收服务、线程和目录。站点前缀来自 [生产配置](../../前端代码/basic-framework-admin/apps/web-ele/.env.production)，当前为 `/admin/`。

规则允许常用网页资源，拒绝源码、sourcemap、隐藏配置、穿越、重复路径、链接和 Windows 设备名；最多 10000 文件，单文件 64 MiB，累计解压 1 GiB。变更合法类型或预算须修改规则并验证目标反例，不绕过校验。

ZIP 不包含 Nginx 配置、Java 服务、Docker 镜像或部署编排。smoke 不执行 JavaScript，不证明动态导入、CSS 二级资源、登录、路由回退、跨域或 API 正常。目标环境按[部署说明](../部署/部署说明.md)验证反向代理及浏览器真实业务。

需要容器交付时，当前前端 `pnpm build:docker` 先调用 `pnpm build:ele`，再以 `apps/web-ele` 为 Docker 构建上下文制作 `basic-framework-admin:local` 镜像。镜像与上述 ZIP 为不同制品；该命令不自动停止、删除或重建运行容器，具体 Nginx 与网络配置按部署文档执行。

## 验证与限制

改动交付工具、配置或代理边界时，运行对应工具测试和实际消费方；不要求为普通页面改动建设额外交付机制。

```powershell
pnpm quality:delivery:test
pnpm quality:analysis:test
pnpm quality:development:test
```

工具测试覆盖合法制品、版本不符、摘要篡改、路径和链接拒绝、资源上限、缺失/外部入口、代理继承、超时与清理；这不替代真实 E2E。`quality:verify` 仍调用原 test:unit/test:e2e，代理包装器、覆盖率和交付 ZIP 为独立入口，不能把未调用的结果写入总门禁结论。
