# 通用防御性模式

<a id="summary"></a>

## 摘要

在异步状态、回调、子进程和文件资源边界保持结果可信、生命周期完整。本页用于 basic-framework 业务实现和测试设计，按真实调用链选择适用的模式，不表示所有模块已经实现这些机制。输入和权限校验仍由接口、服务与持久化边界共同负责。

<a id="results"></a>

## 独立事实与公共契约

独立结果分别上报。例如进程超时后捕获终止信号并以零退出码结束，超时事实仍然成立；退出码、信号、取消及超时不能互相覆盖，调用方应能区分正常完成与提前终止。

公共接口明确失败和取消的表达形式，并在适当边界规范化。依赖方失败、包装层缺陷与消费方异常可能含义不同，不能用一个成功结果或通用错误掩盖来源。约定写在接口所属位置，通过真实消费方覆盖各种来源形式，不照搬其他框架的终止事件协议。

-----

## 业务输入与权限边界

在接口、服务和最终持久化操作处分别保护职责内的边界。前端验证用于操作反馈，后端必须独立检查合法输入、当前身份和授权；隐藏按钮不能代替直接调用接口时的权限拒绝。

| 边界 | 实现与验证要求 |
| --- | --- |
| 缺省、null、空集合、零与 false | 按接口区分未修改、主动清空和实际值；不能用统一真假判断覆盖协议含义 |
| 身份与归属 | 当前用户来自认证上下文，资源归属和数据范围由后端核实；不能相信提交的用户 ID 或部门 ID 已获得授权 |
| SQL 与分页 | 参数绑定替代拼接，排序字段来自白名单；验证非法页码、分页上限及逻辑删除和数据权限条件 |
| 更新与事务 | 校验关联对象、状态与唯一约束；失败后重新查询持久状态，不能用成功响应掩盖部分更新 |
| 文件与对象存储 | 核对路径归属、文件大小、类型及访问方式；元数据与存储操作失败的补偿由负责该调用链的服务定义 |
| 异常与日志 | 真实依赖失败保留明确错误语义，不返回空结果伪装成功；只记录诊断必需内容，排除密码、令牌和密钥 |

业务测试至少覆盖合法输入、关键空值、无权限身份、关联缺失和依赖失败。具体 API、事务与存储契约跟随所属模块，不为套用通用模式新增未需要的重试或补偿机制。

<a id="async"></a>

## 异步完成与因果归属

系统空闲、连接关闭或整体运行中等状态，不能自动证明某个任务成功完成。优先使用任务标识、回执或专属完成结果；只能观察区间时，明确起止条件并把结果归于该区间，不错误归因给其中一条请求。

覆盖无需等待、转换已经发生、取消前未启动和多个任务交错等情况。等待条件必须能够到达，已经完成或不会发生的转换不能无限等待。状态观察与任务结果的区别也适用于性能计时终点。

<a id="cleanup"></a>

## 资源释放与回调隔离

请求停止和已完全停止分别处理。清理流程在约定边界等待自有任务及子进程退出，解除相关监听和订阅，避免迟到的回调重新修改已释放状态；失败和取消路径同样承担清理责任。

需要隔离订阅者的通知分发器应捕获单个回调失败，按契约报告后继续通知其他订阅者，避免异常破坏核心生命周期。顺序业务链若约定遇错终止，则保留该约定，不能为套用隔离模式吞掉错误。日志只保留必要诊断信息，不泄漏敏感内容。

编写涉及资源隔离、同步、超时与清理的测试时，查阅[测试可靠性](测试可靠性.md)的对应章节；排查已有偶发失败时查阅[诊断流程](偶发失败诊断.md)，通用行为验证见[通用测试原则](通用测试原则.md)。

<a id="boundaries"></a>

## 环境与文件边界

向不可信命令或扩展传递环境时，只暴露所需配置并排除凭据等敏感信息。变量名匹配可作为补充检查，不能保证识别所有秘密；同时检查日志、错误输出和临时文件中的泄露风险。

临时资源使用独立、不可预测且受权限保护的位置，创建时防止意外复用已有文件。权限策略按操作系统验证，不把某个平台的权限位当成跨平台保证。

清理路径前核对实际归属、允许范围及链接类型。删除符号链接或目录链接时，仅删除链接本身，选择已验证不会递归进入目标的接口；真实目录与链接分别处理。无法确认路径类型或范围时停止删除，不把原项目的运行时 API 当成通用命令。
