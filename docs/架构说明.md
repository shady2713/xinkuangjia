# Basic Framework 架构说明（v2.0 极简政企版）

本框架定位为**极简、安全合规、可快速二开的企业与政务中后台基础框架**，面向单租户或双平台隔离（超管平台 `super_admin` / 业务平台 `business_admin`）场景。

## 1. 仓库全景

```text
后端代码/basic-framework-boot/     Spring Boot 3.5 + JDK 17（3 模块）
  basic-framework-core/            通用基类、Web/XSS/Jackson、Security、MyBatis-Plus、数据权限、Redis、Excel、@OperateLog AOP
  basic-framework-system/          认证与 SM2、滑块验证码、RBAC、部门、字典、OAuth2、登录/操作日志、极简阿里云短信、统一文件存储
  basic-framework-server/          启动装配、application.yaml、ArchUnit/OpenAPI/Schema 三位一体门禁、Dockerfile
前端代码/basic-framework-admin/    单包 Vite + Vue 3 + TypeScript + Element Plus + Pinia + Vue Router + Tailwind CSS
数据库文件/basic_framework.sql     14 张核心表与最小 RBAC 基线（MySQL 8.0+）
docker-compose.dev.yml             本地回环 MySQL + Redis 开发栈
scripts/runtime/                   本地环境初始化、演示种子与前后端启动脚本
```

## 2. 核心能力清单

### 2.1 安全与等保合规
- **SM2 密码传输**：所有登录、建号、改密、重置密码请求在浏览器端以 `p/t/n`（明文+毫秒时间戳+16 字节随机数）载荷执行 SM2（C1C3C2）加密，后端 BouncyCastle 解密并校验防重放窗口。
- **滑块验证码与防刷锁定**：登录与短信发送前置 anji-plus `blockPuzzle` 滑块验证；密码/短信连续失败触发账号锁定与频率/日上限控制。
- **会话安全**：访问令牌默认 30 分钟空闲超时 + 刷新令牌轮换；停用用户或强退会话立即清理 Redis 令牌缓存；首次登录支持强制改密。
- **审计闭环**：登录审计日志（`system_login_log`）+ 原生 Spring AOP `@OperateLog` 操作审计日志（`system_operate_log`，只读 `SimpleEvaluationContext` 解析 SpEL），支持查询与 Excel 导出。

### 2.2 权限与组织模型
- **双平台硬隔离**：`super_admin` 与 `business_admin` 在用户、角色、菜单、部门层面严格隔离，禁止跨平台访问与提权；写操作缺登录态默认 fail-closed 拒绝。
- **RBAC + 数据权限**：菜单支持目录/菜单/按钮三级结构；角色支持 5 档部门数据权限（全部、指定部门、本部门、本部门及以下、仅本人），由 MyBatis-Plus 拦截器自动注入数据过滤条件。

### 2.3 基础设施
- **统一文件存储**：通过 `FILE_STORAGE_PROVIDER=local|aliyun-oss` 一键切换本地磁盘存储（含路径穿越防护，适用本地开发、CI 与政务内网断网环境）与阿里云 OSS（S3 兼容协议），内置 Apache Tika 魔数校验、50MB 上限及私有对象短时签名访问。
- **极简短信验证码**：仅面向登录与找回密码场景，采用 Redis TTL + Lua 原子单次消费（无 Redis 时自动降级单机内存），内置零 SDK 依赖的阿里云 ACS3-HMAC-SHA256 发送器（本地默认 `enabled=false` 脱敏跳过）。
- **OAuth2.0 开放接口**：支持第三方系统 `client_credentials` 凭证管理与在线会话管控。

## 3. 14 张数据库核心表

| 分类 | 表名 | 用途 |
| --- | --- | --- |
| 组织与账号 | `system_users`、`system_dept` | 管理端用户与部门树 |
| RBAC 权限 | `system_role`、`system_menu`、`system_user_role`、`system_role_menu` | 角色、菜单与绑定关系 |
| 字典 | `system_dict_type`、`system_dict_data` | 系统枚举与前端字典标签 |
| 令牌与开放平台 | `system_oauth2_client`、`system_oauth2_access_token`、`system_oauth2_refresh_token` | 会话令牌与三方客户端 |
| 审计日志 | `system_login_log`、`system_operate_log` | 登录审计与操作审计 |
| 文件记录 | `infra_file` | 统一上传元数据记录 |
