## 已知限制与暂缓工作

当前流程由源码和已有Dockerfile核实，正式环境仍需按本次制品独立验收。

- 数据库由独立迁移入口维护；已有库必须核实旧结构和恢复能力，应用启动不自动迁移。
- 文件地址采用长期公开读取契约，敏感文件需要完整私有授权实现。
- 短信、第三方OAuth2与数据恢复不因应用构建成功而自动通过。
- 目标操作系统、CPU架构与Docker离线安装依赖必须实际确认。
